Kanbango is a kanban board for macOS with Ghostty built in. Drag a task, start a Claude Code session, and watch it work without leaving the board.

A board that runs the work.

The card is the task. The terminal behind it is the session. Both stay in sync.

  • Four columns, drag and drop

    Todo, In progress, Review, Done. Move cards between them, double-click to edit, and set tags and a priority from P0 to P3.

  • A real terminal, not a preview

    Ghostty's runtime is linked into the app and drawn with Metal. A real PTY, your shell, your keys.

  • One card, several sessions

    Each task keeps its own terminal tabs. Start a session, resume an old one by ID, or close it without leaving the card.

  • Status from Claude's own log

    A watcher tails the JSONL files under ~/.claude/projects and marks each session running, idle, or waiting for input.

  • A board for each project

    Point Kanbango at a workspace and it keeps that project's tasks and sessions to itself.

  • Native, not wrapped

    SwiftUI and AppKit in a real .app bundle. The board follows the system's light and dark appearance.

No WebView.
No second window.

The terminal is not a screenshot or a browser tab. Kanbango links Ghostty's static library and draws the surface into its own view, beside the board. Keys go straight to the PTY; frames go through Metal.

Sessions start in a worktree, so two agents can work on the same project without stepping on each other. Kanbango reads the JSONL files Claude Code already writes, which is how a card knows a session is running, idle, or waiting for input.

Tasks live in a JSON file inside your workspace. There is no account and no cloud.

Build from source

Shell 
git clone https://github.com/OneLastHuman/Kanbango.git
cd Kanbango
./scripts/build-ghostty-lib.sh
bash run.sh

Xcode 15 or later and Zig are required. The first build compiles Ghostty; give it a few minutes. Build notes
