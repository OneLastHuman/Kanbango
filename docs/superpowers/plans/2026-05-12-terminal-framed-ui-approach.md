# Terminal Framed UI — 方向文档

## 目标

将 Kanbango 改造成类似 HTML 原型的"面板包裹"视觉效果：
- 整个应用是一个圆角矩形面板
- 终端区域有自己的圆角边框，产生"嵌套"视觉
- 保留原有的布局逻辑和交互

---

## 窗口架构

### 窗口类型
- **Borderless 窗口**（无 macOS 原生标题栏）
- 圆角：13px（macOS 标准圆角值）
- 边框：1px，黑色 15% 透明度
- 背景：透明（内容自带背景色）

### 拖拽逻辑
- **仅顶部区域可拖拽**：窗口顶部 40px 范围
- 下方区域（分隔条、终端等）的鼠标事件不被拦截

### 窗口缩放
- 内容区域随窗口缩放自动填满
- 不出现留白或内容溢出的问题

---

## Traffic Lights（交通灯按钮）

### 位置
- **位于看板面板内部**，不是窗口外部
- 具体位置：看板顶部工具栏（KanbanToolbar）的最左侧
- 工作区路径名称在其右侧

### 样式
- 原生 macOS 风格
- 红（关闭）、黄（最小化）、绿（缩放）三个圆形按钮
- 12px 直径，间距 8px

### 功能
- 关闭：关闭当前窗口
- 最小化：最小化窗口
- 缩放：窗口缩放

## 布局结构

```
┌──────────────────────────────────────────────────────────┐
│  ┌────────────────────────────────────────────────────┐ │
│  │ (13px rounded corners, 1px border)                 │ │
│  │  ┌─────────────┬────────────────────────────────┐ │ │
│  │  │             │                                │ │ │
│  │  │   看板      │         终端                   │ │ │
│  │  │  (Kanban)  │      (Terminal)               │ │ │
│  │  │             │    ┌──────────────────────┐   │ │ │
│  │  │             │    │ Tab Bar              │   │ │ │
│  │  │             │    ├──────────────────────┤   │ │ │
│  │  │             │    │                      │   │ │ │
│  │  │             │    │   SurfaceView        │   │ │
│  │  │             │    │                      │   │ │
│  │  │             │    └──────────────────────┘   │ │
│  │  └─────────────┴────────────────────────────────┘ │
│  └────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────┘
```

### 分层说明

1. **窗口层（Window）**
   - Borderless，无标题栏
   - 透明背景，圆角 13px，阴影

2. **容器层（ContainerView）**
   - 填满整个窗口
   - 圆角裁剪 + 边框效果
   - 仅顶部 40px 可拖拽

3. **内容层（ContentView）**
   - HSplitView 横向布局
   - 左边：看板面板
   - 右边：终端面板

4. **终端面板（TerminalFrameView）**
   - 自己的边框和圆角
   - 内部包含 TabBar + SurfaceView

## 关键组件

### 1. DemoApp.swift
- 创建 borderless NSWindow
- 创建 DraggableContainerView 作为根容器
- 处理窗口拖拽、圆角、边框

### 2. KanbanToolbar
- 包含 TrafficLightsView（最左侧）
- 工作区路径名称
- 新建任务按钮

### 3. TerminalFrameView
- 通用包装组件
- 为内容添加圆角边框效果

### 4. ContentView
- HSplitView 横向布局
- 左边看板，右边终端
