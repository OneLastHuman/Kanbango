# Kanbango Logo 设计简报

## 项目背景

### 项目名称
**Kanbango** — 一个 macOS SwiftUI 应用

### 核心定位
将 Ghostty 终端嵌入到看板界面中，用于管理 Claude Code 会话的工具。

### 解决什么问题
- 在看板上管理多个 Claude Code 工作会话
- 通过拖拽任务卡片组织工作流程
- 实时监控 Claude Code 会话状态（running/idle/needInput）
- 支持工作区切换，每个项目独立管理

### 技术栈
- **前端**: SwiftUI（macOS 原生）
- **终端**: Ghostty（通过 C API 集成）
- **数据**: JSONL 文件监控（Claude Code 会话记录）
- **存储**: 本地 JSON + UserDefaults

### 目标用户
- 使用 Claude Code 的开发者
- 需要管理多个 AI 会话的项目管理者

## Logo 设计方向建议

### 命名拆解
- **Kanban** → 看板、列（Column）、卡片（Card）、网格
- **Go** → 终端命令行、"跑起来"、执行
- **Ganban**（日语"看板"音译）→ 专业、简洁

### 核心关键词（用于 moodboard）
| 关键词 | 视觉联想 |
|--------|----------|
| 终端 / Terminal | 命令行、$ 提示符、黑底绿字、像素 |
| 看板 / Kanban | 列（Column）、卡片、拖拽、网格 |
| 会话 / Session | 线程、时间线、连接 |
| 开发者 / Dev | 代码、终端、工具 |
| macOS | 简洁、圆润、苹果生态 |

### 建议方向

#### 方向 A: 终端 + 看板融合
- 将终端窗口的轮廓与看板列/卡片结合
- 可以用 `$` 符号作为视觉锚点，演变成列的形状

#### 方向 B: 字母 K + 终端元素
- 用字母 K 的几何形状
- 融入终端窗口的标题栏、命令行提示符等元素

#### 方向 C: 抽象卡片流
- 抽象的看板卡片堆叠/流动感
- 融入 Ghostty 的品牌调性（如果有的话）

### 颜色建议
| 用途 | 颜色 |
|------|------|
| 主色 | Ghostty 相关色（待确认）或 macOS 蓝色 |
| 强调色 | 终端绿色（经典 `$` 提示符绿）|
| 背景 | 透明或深色（适配 macOS 图标风格）|

### 图标规范（macOS App Icon）
- 需要尺寸: 16, 32, 64, 128, 256, 512, 1024 px
- 圆角: macOS Big Sur 以后使用圆角矩形
- 风格: 简洁、扁平化或轻拟物
